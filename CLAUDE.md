# CLAUDE.md

Jogo em HTML puro (canvas) "Lenhador Ilegal", do projeto Guardiões da Floresta. Projeto de alunos, orientado pelo professor Adilson. O objetivo pedagógico é mostrar as consequências do desmatamento ilegal.

## Regras do projeto

- Tudo fica em um único `index.html` (HTML, CSS e JavaScript). Sem frameworks, sem build, sem dependências, sem imagens externas: tudo é desenhado no canvas.
- Idioma da interface e dos comentários: português do Brasil.
- O jogo é publicado no GitHub Pages a partir da branch `main`, pasta raiz.
- Controles: W A S D mover, Espaço cortar, E vender, R reiniciar na tela final.
- Os números que mudam a dificuldade ficam juntos, no bloco "Ajustes do jogo" (`SUSPEITA_POR_ARVORE`, `META_DINHEIRO`, `MUNDO`).

## Cuidados ao alterar

- Mantenha o código simples e legível: os alunos precisam conseguir ler e editar.
- A tela final deve continuar mostrando a mensagem sobre os danos do desmatamento ilegal.
- Teste abrindo o `index.html` no navegador antes de enviar.
